# プロジェクト タスク管理 (Task Management)

本プロジェクト（Dinosaurs Website）の小プロジェクト・カテゴリ別タスク管理ディレクトリです。
チャットセッションが増えても、ここを参照することでいつでも最新のコンテキストと進捗を引き継いで作業を再開できます。

---

## 📁 タスク一覧

| ファイル | 対象分野 | 主な内容 |
| :--- | :--- | :--- |
| [archive.md](./archive.md) | **恐竜アーカイブ / 図鑑** | 詳細ページ (`dictionary/[id].astro`)、一覧、Cyber骨格アセット、接地・サイズ調整 |
| [articles.md](./articles.md) | **記事・コンテンツ作成** | 恐竜個別データ (`content/dinosaurs/`)、特集記事 (`content/topics/`) の執筆・更新 |
| [seo.md](./seo.md) | **SEO・パフォーマンス** | メタタグ、構造化データ (JSON-LD)、サイトマップ、内部リンク、Core Web Vitals |

---

## 🤖 エージェント運用ルール

1. **タスク開始時**:
   ユーザーから「SEO進めて」「記事を書いて」「アーカイブを修正して」等の指示があった場合、エージェントは該当するタスクファイルを自動的に読み取り、未完了タスク（`- [ ]`）を確認して作業を開始します。
2. **タスク完了時**:
   作業が完了したら、該当ファイルのチェックボックスを `- [x]` に更新し、必要に応じて完了日付やメモを追記します。
3. **新規タスク発生時**:
   新しい課題や要望が出た場合、該当ファイルに新しいタスクを追加します。
